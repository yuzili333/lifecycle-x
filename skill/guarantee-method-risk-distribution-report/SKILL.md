# 担保方式风险分布分析报告

## 目标与字段

生成“担保方式风险分布（笔数+金额）”报告。业务角色为主要担保方式名称、最新风险五级分类、金额指标和可选合同流水号。本模板只生成统计表和分析结论，不生成图表。

字段优先使用用户已确认的 `#` 引用，其次匹配当前真实 Schema 的业务名称，再由模型依据真实名称、类型和脱敏样例推荐并经本地校验。不得依赖表字典、固定英文映射、物理后缀或不存在的字段。

用户未指定金额指标时使用贷款余额并统一计算为万。单位只从真实字段名称或 Schema 识别：元除以 `10,000`，万或万元保持数值，亿或亿元乘以 `10,000`。单位无法确认时请求用户确认，不猜测换算关系。

## 统计口径

主要担保方式先去除“代码--名称”中的代码前缀，再归并为保证、信用、其他、抵押、质押五类。归并规则为“保证金→质押”；其余依次按抵押、质押、保证、信用关键词识别；无法归入前述类别的非空值归入其他，空值排除。

五级分类归并为正常、关注、不良；不良包含源值“不良”、次级、可疑、损失。不得从粗粒度分类反向拆分。专业担保公司保证不良数只统计原始担保方式名称包含“专业担保公司保证”且风险归入不良的记录。

合同笔数优先按合同流水号去重。同一流水号的担保方式、分类和金额一致时合并为一笔；流水号缺失、含空值或同一流水号存在冲突时，整份统计统一降级为有效记录行数。有效记录必须具备非空担保方式、可识别分类和可解析金额。

金额解析、换算、累计、比率和对账全程使用 `Decimal`，最终 JSON 序列化时才转为 number。每类的笔数及金额不良率、关注率使用该类真实分子除以对应合计；整体比率使用全量分子除以全量分母。分母为零时比率为 `null`。

## 工具职责

### SQL 工具

只执行查询脚本并返回查询结果。读取筛选范围内的主要担保方式、五级分类、金额和可用合同流水号明细；禁止 `LIMIT`、聚合函数、`GROUP BY` 或 `DISTINCT` 完成统计。不得生成指标、分类结论或报告内容。

### Python 工具

只执行统计脚本并输出计算结果。系统依据本 Skill 的只读统计配方和 SQL Artifact 真实字段生成受控脚本；该脚本遵循客户端统一的紧凑统计脚本约束，执行模型不得重新编写、扩展或修复整段统计程序。

脚本从 stdin 的完整 `rows` 读取 SQL Artifact，完成必要清洗、合同去重或行数降级、担保方式与风险归并、二维聚合、笔数及金额比率计算、专业担保公司保证不良数统计和确定性对账。stdout 只输出“Python 统计结果契约”对应 JSON。

Python 禁止生成 Markdown，也不负责字段发现、SQL 查询、报告结构、展示格式、分析结论或内容审核。字段缺失、候选冲突或金额单位不明确时停止当前步骤并提示真实候选，不得退回模型生成完整脚本。

### 报告模型

统一负责报告标题、统计口径说明、Markdown 表格、数字与单位格式、分析结论和内容一致性审核。只能使用 Python 已计算结果，不重新统计原始数据。

表格依次展示保证、信用、其他、抵押、质押和合计，包含正常、关注、不良及合计的笔数、金额、不良率和关注率。金额使用万和千分位；比率乘以 100 后保留两位，`null` 展示 `--`。

分析结论仅覆盖有数据依据的笔数、金额、风险缓释和关注信号，不增加图表、模板外指标或无数据依据的建议。不得输出示例值、Artifact ID、工具名称、脚本、本地路径或 HTML。溯据卡由系统追加。
