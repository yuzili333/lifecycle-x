# 重点风险客户分析报告

## 目标与字段

生成“重点风险客户分析（含金额占比）”报告。重点风险客户是最新风险分类为关注或不良的合同记录，不良包含次级、可疑、损失。

核心业务角色为合同流水号、客户名称、最新风险分类和贷款余额。辅助角色为一级分行名称、年初风险分类、最新风险分类结果、主要担保方式名称、客户所属省/市、国标行业投向名称、业务品种名称、短中长期贷款标识和合同金额。

“省份”对应真实字段“客户所属省/市”，“行业”对应真实字段“国标行业投向名称”。不得根据分行、客户名称或地址推断省份，也不得使用其他行业字段替代。

字段优先使用用户已确认的 `#` 引用，其次匹配当前真实 Schema 的业务名称，再由模型依据真实名称、类型和脱敏样例推荐并经本地校验。不得依赖表字典、固定英文映射、物理后缀或不存在的字段。核心角色缺失时请求确认；辅助字段缺失时保留 `null`，由报告模型展示 `--`。

## 统计口径

SQL 必须查询全样本，不能先筛选关注或不良，因为全样本合同数和贷款余额是占比分母。

合同笔数优先按合同流水号去重。同一流水号的客户、分类和金额一致时合并为一笔；流水号缺失、含空值或同一流水号存在冲突时，整份统计统一降级为有效记录行数。同一客户存在多笔合同时不合并为一个客户。

金额统一计算为万：元除以 `10,000`，万或万元保持数值，亿或亿元乘以 `10,000`。解析、累计、占比和对账全程使用 `Decimal`，最终 JSON 序列化时才转为 number。分母为零时占比为 `null`。

非正常为关注和不良合计。正常转非正常劣变只在年初分类字段存在时计算。客户明细按不良优先、关注其次，再按贷款余额降序和原始顺序稳定排序，禁止 Top N 截断。

## 工具职责

### SQL 工具

只执行查询脚本并返回全样本明细。查询核心字段和真实存在的辅助字段，禁止 `LIMIT`、聚合函数、`GROUP BY`、`DISTINCT` 或预先按风险分类过滤。不得生成统计、特征结论或报告内容。

### Python 工具

只执行统计脚本并输出计算结果。从 stdin 的完整 `rows` 读取 SQL Artifact，完成必要清洗、去重或降级、风险归并、重点风险筛选、金额及占比计算、迁徙统计、明细排序和业务期限/行业/省份分组统计。

脚本遵循客户端统一的紧凑统计脚本约束，使用辅助函数、映射表和循环，禁止按风险类别、行业或省份复制统计分支。输出只包含：

- 真实字段、单位、结构化笔数口径、有效和排除记录数。
- 全样本与关注、不良、非正常的笔数、金额及占比纯数值。
- 正常转非正常劣变笔数。
- 全部重点风险合同明细，金额和占比只输出数值。
- 业务期限、行业和省份的结构化分布指标。
- 样本、明细、排序和金额对账布尔值。

Python 禁止生成 Markdown、报告标题、章节、编号结论、摘要句、风险建议、数据质量说明句、千分位、亿元文字、百分比展示字符串或内容审核文字。不得重复输出“不良客户表”Markdown；报告模型从重点风险合同明细中选择 `riskGroup=nonperforming` 的记录组成表格。

### 报告模型

统一负责报告标题、摘要、Markdown 主表与不良客户表、数字和单位格式、特征分析结论、结构组合和内容一致性审核。只能使用 Python 已计算数值和结构化分布，不重新统计原始数据。

金额小于 `10,000万` 时展示带千分位的万元；大于等于 `10,000万` 时按 `10,000万 = 1亿` 格式化并保留两位，不添加“约”。比率乘以 100 后保留两位，`null` 展示 `--`。

特征分析围绕业务期限、不良合同表、关注客户、可用的风险迁徙以及行业和省份分布组织，不增加图表、模板外指标或无数据依据的建议。不良合同表行数必须与计算结果中的不良笔数一致。不得输出示例企业、Artifact ID、工具名称、脚本、本地路径或 HTML。溯据卡由系统追加。
