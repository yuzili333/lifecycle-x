# 各分行资产质量状况分析报告

## 目标与字段

生成“各分行资产质量状况（笔数+金额）”报告。业务角色为一级分行名称、最新风险五级分类、金额指标和可选合同流水号。

字段优先使用用户已确认的 `#` 引用，其次匹配当前真实 Schema 的业务名称，再由模型依据真实名称、类型和脱敏样例推荐并经本地校验。不得依赖表字典、固定英文映射、物理后缀或不存在的字段。

用户未指定金额指标时使用贷款余额并统一计算为万。单位只从真实字段名称或 Schema 识别：元除以 `10,000`，万或万元保持数值，亿或亿元乘以 `10,000`。单位无法确认时请求用户确认，不猜测换算关系。

## 统计口径

五级分类归并为正常、关注、不良；不良包含源值“不良”、次级、可疑、损失。不得从粗粒度分类反向拆分。

合同笔数优先按合同流水号去重。同一流水号的分行、分类和金额一致时合并为一笔；流水号缺失、含空值或同一流水号存在冲突时，整份统计统一降级为有效记录行数。有效记录必须具备分行、可识别分类和可解析金额。

金额解析、换算、累计、比率和对账全程使用 `Decimal`，最终 JSON 序列化时才转为 number。每个分行的笔数不良率、关注率和金额不良率、关注率均使用该分行真实分子除以对应合计；全行平均率使用所有分行全量分子除以全量分母，禁止平均分行比率。分母为零时比率为 `null`。

## 工具职责

### SQL 工具

只执行查询脚本并返回查询结果。读取筛选范围内的一级分行、五级分类、金额和可用合同流水号明细；禁止 `LIMIT`、聚合函数、`GROUP BY` 或 `DISTINCT` 完成统计。不得生成指标、排序结论或报告内容。

### Python 工具

只执行统计脚本并输出计算结果。从 stdin 的完整 `rows` 读取 SQL Artifact，完成必要清洗、去重或降级、分类归并、按分行聚合、比率计算、排序键和确定性对账。

脚本遵循客户端统一的紧凑统计脚本约束，使用辅助函数、映射表和循环，禁止按分行或风险类别复制统计分支。输出只包含真实字段与单位、结构化笔数口径、有效及排除记录数、全部分行及全行合计的纯数值指标、分行数量和对账布尔值。分行数据按不良率降序、关注率降序、分行名称升序稳定排序。

Python 禁止生成 Markdown、报告标题、章节、编号结论、风险建议、数据质量说明句、千分位、单位拼接、百分比展示字符串或内容审核文字，也不得为同一指标输出数值与展示两份字段。

### 报告模型

统一负责报告标题、统计口径说明、Markdown 表格、数字与单位格式、编号结论和内容一致性审核。只能使用 Python 已计算结果，不重新统计原始数据。

表格包含每个真实分行，列顺序为分行名称、正常/关注/不良/合计笔数、笔数不良率和关注率、正常/关注/不良/合计金额、金额不良率和关注率。金额使用万和千分位；比率乘以 100 后保留两位，`null` 展示 `--`。

分析结论基于已排序分行和全行合计说明不良分行、关注分行及全行平均水平，不增加图表、模板外指标或无数据依据的建议。不得输出示例值、Artifact ID、工具名称、脚本、本地路径或 HTML。溯据卡由系统追加。
