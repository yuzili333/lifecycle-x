# 整体风险分类分布分析报告

## 目标与字段

生成“整体风险分类分布（笔数+金额）”报告。业务角色为最新风险五级分类、贷款余额、可选的最新风险分类结果、合同金额和合同流水号。

字段优先使用用户已确认的 `#` 引用，其次匹配当前真实 Schema 的业务名称，再由模型基于真实名称、类型和脱敏样例推荐并经本地校验。禁止依赖表字典、业务字段 ID、历史英文映射、物理后缀或不存在的字段。“贷款余额”和带明确单位的“贷款余额(万元)”属于同一业务角色，但 SQL 与 Python 必须使用真实字段名。

单位只从字段名称或 Schema 单位识别，不根据数值大小猜测。贷款余额是必需字段；合同金额和分类结果不存在时允许省略对应摘要或明细。

## 统计口径

五级分类固定为正常、关注、次级、可疑、损失；源值“不良”只能作为不良汇总，不能反向拆分。若只有分类结果字段，可根据真实值前缀或名称归并到五级分类。

合同笔数优先按合同流水号去重。同一流水号的分类、分类结果和金额一致时合并为一笔；流水号缺失、含空值或同一流水号数据冲突时，整份统计统一降级为有效记录行数。有效记录必须具备可识别分类。

金额解析、累计、占比和对账全程使用 `Decimal`，最终 JSON 序列化时才转为 number。笔数占比分母是有效合同或有效行总数；金额占比分母是同一粒度下贷款余额总计。分母为零时占比为 `null`。不良类为次级、可疑、损失合计，Python 必须直接输出不良汇总，报告模型不得自行求和。

## 工具职责

### SQL 工具

只执行查询脚本并返回查询结果。读取筛选范围内的分类、分类结果、贷款余额、可用合同金额和合同流水号明细；禁止 `LIMIT`、聚合函数、`GROUP BY` 或 `DISTINCT` 完成报告统计。不得生成指标、结论或报告内容。

### Python 工具

只执行统计脚本并输出计算结果。从 stdin 的完整 `rows` 读取 SQL Artifact，完成必要清洗、去重或降级、分类归并、分组聚合、占比、不良汇总和对账。

脚本遵循客户端统一的紧凑统计脚本约束，使用辅助函数、映射表和循环，禁止按风险类别复制统计分支。输出只包含真实字段和单位、结构化计数口径、有效及排除记录数、总计、五级分类分布、可选分类结果明细、不良汇总和校验布尔值。数值字段只输出一次。

Python 禁止生成 Markdown、报告标题、章节、结论段落、数据质量说明句、合同金额摘要子句、千分位、亿元文字、固定小数展示字符串或内容审核文字。

### 图表工具

基于 Python 结果生成两张可选图表：五级分类笔数饼图使用 `category` 和 `count`；贷款余额柱状图使用 `category` 和 `loanBalance`。图表失败不阻塞报告，报告只引用本轮成功图表。

### 报告模型

统一负责报告标题、摘要、Markdown 结构、表格、单位与小数格式、分析结论和内容一致性审核。只能使用 Python 已计算结果，不重新统计原始数据。

表格保留已确认的贷款余额源单位。报告文字可将金额格式化为亿元：元除以 `100,000,000`，万元除以 `10,000`，亿元保持数值，使用 `ROUND_HALF_UP` 保留三位且不添加“约”。报告包含五级分类表、可选分类结果明细、可用图表和 `【笔数维度】`、`【金额维度】`、正常类内部细分结论。不得输出示例值、Artifact ID、内部工具信息、本地路径或 HTML。溯据卡由系统追加。
