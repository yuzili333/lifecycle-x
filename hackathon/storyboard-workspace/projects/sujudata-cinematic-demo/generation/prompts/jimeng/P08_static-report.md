# P08_static-report

参考@图片1中的两位人物身份、服装、会议桌构图和纸面报告。会议桌双人中景，研发工程师将一页正确但静态的分析报告平稳放在两人之间，右手把黑色中性笔自然放在报告旁，随后双手保持稳定；业务主管只用右手食指沿柱状图缓慢移动一次，左手自然放在自己身前。两人肩颈放松、保持舒适间距，视线共同落在报告上，神情平和专注，呈现专业协作与口径确认，不是质疑、争执或风险处置。摄影机从纸面报告轻轻抬到两人上半身，保持同一侧轴线，以业务主管手指停在图表末端结束。

固定要求：16:9，写实电影摄影，克制而温和的企业纪录片质感，35mm电影镜头观感，真实皮肤与织物纹理，冷色自然晨光从画面左侧进入，暖色台灯辅光，轻微胶片颗粒。保持同一位38—42岁东亚女性业务主管：黑色低马尾、深炭灰西装、低饱和青绿色衬衫、银色腕表；保持同一位30—36岁东亚男性研发工程师：黑色短发、深海军蓝针织外套、浅灰衬衫。人物眉眼放松、嘴唇自然，不皱眉、不抿嘴、不紧张、不对峙、不夸张微笑；人物不说话，不生成对白口型。只做一个主要动作和一种运镜。两人的手部数量和位置必须连续，不同时指向报告，不新增手臂、手掌或手指。不得变脸、换装、换办公室、增加人物、生成字幕、标题、品牌水印、乱码、客户数据、畸形手、多余肢体、物体漂浮、镜头旋转、自动授信、自动风险判断或风险处置。
