# Character Bible

## char_business_lead_v1

- Name: 林主管（虚构制作代号，不在画面显示）
- Role: 银行存续期业务主管，理解业务问题、指标和报告口径。
- Age range: 38—42岁成年东亚女性。
- Face: 椭圆脸、自然肤质、克制专业表情；非任何真实人物肖像。
- Hair: 黑色直发，及肩长度，低位马尾；额前无明显刘海。
- Body / silhouette: 中等身高，挺直但自然，不以夸张疲惫表现压力。
- Wardrobe: 炭灰色单排扣西装外套、低饱和青绿色衬衫、深色长裤。
- Signature props: 简洁银色腕表、深蓝硬壳笔记本、黑色中性笔。
- Never change: 成年身份、发型、炭灰外套、青绿色衬衫、银色腕表。
- Current approved reference: `media/keyframes/S01_task-arrives_v01.png`；S02—S06已按该锚点完成连续性审查。

## char_engineer_v1

- Name: 研发同事（虚构制作代号）
- Role: 正常承担既有迭代任务、与业务协作确认需求的研发工程师。
- Age range: 30—36岁成年东亚男性。
- Face: 不作正面特写，以侧影、肩背和手部为主。
- Hair: 黑色短发，整洁自然。
- Body / silhouette: 普通成年人体态，坐姿专注。
- Wardrobe: 深海军蓝针织外套、浅灰衬衫，无领带。
- Signature props: 深灰笔记本电脑、无品牌马克杯。
- Never change: 服装色、专业平静状态；不得表现冷漠、拖延或嘲讽。
- Current approved reference: `media/keyframes/S03_requirement-handoff_v01.png`。

## char_colleague_v1

- Name: 汇报参会同事（虚构制作代号）
- Role: 在静态报告交付后提出自然下钻问题。
- Age range: 35—45岁成年东亚人。
- Face: 仅侧影或手部入镜，不建立独立肖像。
- Wardrobe: 中性深色商务便装。
- Signature props: 指向报告图表的手、无品牌会议笔。
- Never change: 专业、好奇而非质疑或责难的肢体语言。
- Current approved reference: `media/keyframes/S05_static-report-followup_v01.png`。
