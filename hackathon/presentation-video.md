# Hackathon 电影级视频

## 工作流

Hackathon 项目
      ↓
codex-storyboard
      ↓
Story / Hook / Pain / Turning Point
      ↓
SHOTBOOK
      ↓
──────── Product Reveal ────────
      ↓
video-shotcraft
      ↓
Product UI / Demo / Motion / WOW
      ↓
video-talkcraft
      ↓
Voiceover / Subtitle / SFX
      ↓
Remotion
      ↓
Final MP4

### 视频段落说明

|         时间 | 内容                 | Skill                  |
| ---------: | ------------------ | ---------------------- |
|       0–5s | Hook               | storyboard + talkcraft |
|      5–15s | Character          | talkcraft              |
|     15–25s | Problem            | talkcraft              |
|     25–32s | Pain escalation    | talkcraft              |
|     32–36s | Turning Point      | talkcraft              |
| **36–40s** | **Product Reveal** | **shotcraft**          |
|     40–55s | Core interaction   | shotcraft              |
|     55–70s | AI workflow        | shotcraft              |
|     70–80s | WOW Result         | shotcraft              |
|     80–86s | Impact             | talkcraft + shotcraft  |
|     86–90s | Logo / Tagline     | shotcraft              |

- shot array
- shot type
- duration
- script
- visual description
- generation method
- DESIGN.md
